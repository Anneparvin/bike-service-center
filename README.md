# Node.js Express API with Prisma ORM

This project name is (bike-servicing-center) is a **RESTful API** owned by FORIDA PARVEN, built using **Node.js**, **Express.js**, and **Prisma ORM**. It provides a clean and scalable backend for modern web and mobile applications. The API supports **CRUD (Create, Read, Update, Delete)** operations, allowing users to manage data in a **PostgreSQL** or **MySQL** database with ease.

## Features:
- **Express.js**: A fast and minimalist web framework for building APIs.
- **Prisma ORM**: Simplifies database interactions and enables fast, type-safe queries with **PostgreSQL** and **MySQL** support.
- **TypeScript**: Provides type safety, reducing bugs and improving code maintainability.
- **Environment Configuration**: Uses **dotenv** to manage environment variables (e.g., database credentials).
- **Modular Code Structure**: Organized file structure for scalability and ease of maintenance.
- **Error Handling**: Comprehensive error handling that provides consistent responses.

## Technologies Used:
- **Node.js**: JavaScript runtime for building scalable applications.
- **Express.js**: Web framework for building REST APIs.
- **Prisma ORM**: Database toolkit for Node.js that supports multiple databases like **PostgreSQL**, **MySQL**, and **SQLite**.
- **TypeScript**: Adds type safety to JavaScript for more reliable and maintainable code.
- **dotenv**: Environment variable management for secure configuration.
